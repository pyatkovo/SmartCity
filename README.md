## 📌 Описание

Лендинг для платформы **умного дома**, выполненный на **чистом HTML и CSS**.  
Проект ориентирован на демонстрацию преимуществ и удобства SmartCity-технологий.

Сайт имеет:
- минималистичный и **стильный интерфейс**,
- **адаптивный дизайн**, подходящий для всех устройств.

## 🎯 Особенности

- 📱 Полностью адаптивный лендинг
- 💡 Современный чистый дизайн
- 🔧 Реализован без JavaScript и фреймворков
- 🏠 Ориентация на тематику «Smart Home / Smart City»

## 🛠 Используемые технологии

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
